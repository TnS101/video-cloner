# Video Cloner Bootstrap Adaptation

This overlay is derived from UNFAIR ADVANTAGE Project Bootstrap v1.1 but intentionally adapts it to the late-stage, already-clean Video Cloner repository.

## Changes from the generic pack

1. **GitHub-first context** — GitHub `main` is authoritative; browser-context ZIP generation is fallback only.
2. **No `.agent` collision** — `.agent` remains the existing Resolve queue/runtime namespace. Project-management reports/templates use `.project_ops`.
3. **No project restart** — the cleanup tag and current canonical package are accepted baseline; phases start from live Resolve acceptance, not generic PH0 research/build.
4. **Conditional OSS research** — 5–10 option research is required only when selecting/changing a material mechanism/dependency/adapter. It is not required for P001 acceptance.
5. **No hard Ponytail SPOF** — relevant global skills are used when present; absence blocks only if a Plan explicitly requires a named skill.
6. **Existing README preserved** — the product README remains product-facing and is not replaced by bootstrap documentation.
7. **Acceptance separated from repair** — P001 performs live Resolve acceptance only. A defect becomes a new Plan rather than a patch loop.
8. **Tracker mirrors reality** — `PROJECT_TRACKER.xlsx` is initialized to the current Video Cloner state and P001.
